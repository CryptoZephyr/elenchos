# Elenchos docs

Documentation site for [Elenchos](https://github.com/CryptoZephyr/elenchos), a local Kane-backed verification loop for AI coding agents.

Visual language follows the light chrome templates in `Downloads/Elenchos template`. Components follow the `ui-toolbox` hierarchy: shadcn-style primitives, React Bits motion (SpotlightCard, GlareHover), project tokens in authority.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Pages: Home, Quickstart, Verification, Kane, MCP, Agents, Evidence, Security.
